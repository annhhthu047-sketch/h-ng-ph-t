# Hưng Phát AI Agent - Hệ Thống Đánh Giá Thị Trường Mở Rộng

Hệ thống AI Agent tự động hóa đánh giá và xếp hạng địa bàn kinh doanh tiềm năng phục vụ Công ty Hưng Phát, áp dụng cơ chế kiểm soát con người (Human-in-the-loop).

## 🌟 Tính Năng Chính
- **Làm sạch & Đồng bộ dữ liệu**: Tự động loại bỏ trùng lặp, quy đổi mốc thời gian về cùng năm chuẩn hóa.
- **Đánh giá độ phù hợp phần mềm**: Đối chiếu tính năng WMS với nhu cầu khách hàng và cự ly triển khai.
- **Tính điểm & Minh bạch nguồn dẫn**: Ma trận chấm điểm 3 trụ cột (Quy mô 30%, Độ khớp 35%, Năng lực triển khai 35%).
- **Kiểm soát rủi ro (Veto Rule & HITL)**: Cảnh báo và phê duyệt loại trừ với địa bàn vi phạm điều kiện tiên quyết.
- **Báo cáo & Dashboard**: Giao diện trực quan Pastel Glassmorphism và xuất báo cáo đề xuất cho cấp quản lý.

## 🚀 Hướng Dẫn Khởi Chạy
1. Cài đặt Python (phiên bản 3.10 trở lên).
2. Chạy file khởi động:
   ```cmd
   RUN_AGENT.bat
   ```
   hoặc chạy lệnh:
   ```bash
   python server.py
   ```
3. Mở trình duyệt và truy cập: `http://localhost:8000`
