01 • BỐI CẢNH & GIÁ TRỊ THỰC TIỄN

Trang Web Giải Quyết Vấn Đề Gì & Có Tác Dụng Gì?

Thu hẹp khoảng cách giữa bảng số liệu thô nhiều sai sót và báo cáo quyết định kinh doanh chính xác.

⚠️ Khó khăn khi xử lý thủ công
  • Dữ liệu rời rạc & lỗi định dạng: Tệp Excel/CSV dễ bị lỗi font tiếng Việt (UTF-8), trùng lặp dòng, ô trống hoặc người dùng vô tình nạp nhầm tệp rỗng dẫn đến sai lệch.
  • Tốn nhiều giờ tổng hợp trên Excel: Nhân sự kinh doanh phải lọc tay từng cột, viết hàm cộng trừ phức tạp và vẽ lại biểu đồ mỗi khi có số liệu kỳ mới.
  • Dễ thao tác nhầm, thiếu nút quay lui: Khi lỡ xóa nhầm dòng hoặc sửa sai công thức, việc kiểm tra lại lỗi nguồn rất mất thời gian.
  • Báo cáo thiếu gắn kết: Số liệu Dashboard, nhận xét nguyên nhân và văn bản gửi quản lý nằm tách rời, khó chỉnh sửa trực tiếp khi cần cập nhật gấp.
✨ Giải pháp & Tác dụng với người dùng
  • Nạp đa nguồn & Chặn file rỗng an toàn: Đọc Excel, CSV, dán link Google Sheet / Lark Base; tự khử lỗi font tiếng Việt và cảnh báo dừng ngay khi file 0 dòng.
  • Làm sạch thông minh + Hoàn tác 25 bước: Bấm 1 chạm AI làm sạch hoặc gõ lệnh tiếng Việt (VD: "Xóa 5 dòng dữ liệu đầu tiên") kèm nút ↩️ Hoàn tác an toàn tuyệt đối.
  • Dashboard BI & Nhận xét tức thì: Tự nhận diện cột Doanh thu, Chi phí, Kênh bán; tính ngay ROS, AOV, vẽ biểu đồ động kèm phân tích chi tiết bên dưới.
  • Tiết kiệm thời gian, chuẩn hóa đầu ra: Sinh sẵn báo cáo chuẩn doanh nghiệp cho phép gõ sửa trực tiếp, hỏi Chatbot AI 24/7 và tải ngay bản HTML/PDF.
Tác dụng cốt lõi: Người dùng không cần giỏi lập trình vẫn tạo được báo cáo BI chuẩn xác Slide 2 / 7
02 • QUY TRÌNH XÂY DỰNG WEB (ANTIGRAVITY & API)

Trang Web Được Tạo Ra Như Thế Nào?

Kết hợp tư duy nghiệp vụ Quản trị Kinh doanh với nền tảng AI Agent Google Antigravity, hệ sinh thái Web API và hạ tầng Vercel.

Bước 1 · Nghiệp vụ & UI

Thiết kế luồng & Giao diện

Định hình quy trình 4 bước (Nạp ➔ Làm sạch ➔ BI ➔ Xuất báo cáo) theo phong cách Glassmorphism Hồng – Xanh Pastel, hỗ trợ Sáng/Tối.

UI/UX QTKD Glassmorphism
Bước 2 · AI Coding Agent

Phát triển với Antigravity

Sử dụng Google Antigravity chuyển mô tả tiếng Việt thành code chuẩn: giao diện web HTML/CSS/JS kết hợp engine Python chạy cục bộ.

Google Antigravity JS ES6+ Python
Bước 3 · Kết nối API

Tích hợp API & Thư viện

Dùng Fetch API lấy dữ liệu từ Google Sheets (gviz/tq) & Lark Base; kết hợp SheetJS đọc Excel, Chart.js vẽ biểu đồ, Blob API xuất file.

Google Sheet API SheetJS Chart.js
Bước 4 · Bảo mật & Web

Đóng gói & Triển khai

Đẩy code lên GitHub, tự động deploy lên Vercel kèm cấu hình HTTP Security Headers (vercel.json) và Runtime Shield chống sập trang.

GitHub Vercel Edge Security Shield
🤖 Vai trò của Google Antigravity: Đóng vai trò "cộng sự kỹ thuật AI", giúp thiết kế cấu trúc SPA không lỗi trang, viết bộ nhận diện lệnh tiếng Việt (NLP), hệ thống hoàn tác 25 bước và tối ưu trải nghiệm người dùng nhanh gấp nhiều lần lập trình thủ công.
🔌 Cơ chế API & An toàn dữ liệu: Mọi thao tác đọc Excel (FileReader), lưu tài khoản (LocalStorage), lọc bảng và xuất báo cáo (Blob API) chạy trực tiếp trên trình duyệt; chỉ gọi API mạng khi người dùng chủ động dán link Google Sheet / Lark Base.

04 • CƠ CHẾ VẬN HÀNH THÔNG MINH

4 Điểm Sáng Trong Cơ Chế Vận Hành Hệ Thống

Bên dưới giao diện đơn giản là các mô-đun tự động hóa xử lý dữ liệu và bảo vệ chất lượng báo cáo.

1. Nạp Đa Nguồn & Chốt Chặn File Rỗng
Input Guard
Excel/CSV + Google Sheet + Lark Base

Hỗ trợ cả tệp máy tính và link trực tuyến; tự sửa lỗi font tiếng Việt UTF-8 và kích hoạt Empty File Guard để dừng ngay khi gặp file rỗng, tránh tạo ra phân tích ảo.

2. Làm Sạch NLP Tiếng Việt & Hoàn Tác
Undo 25 Bước
Hiểu lệnh tự nhiên + Kiểm duyệt thủ công

Gõ lệnh như "Xóa 5 dòng dữ liệu đầu tiên" hoặc "Điền ô trống Khu vực bằng Toàn quốc"; mọi sửa đổi đều có thể quay lui tức thì bằng nút ↩️ Hoàn tác.

3. Phân Tích BI Động Theo Ngữ Cảnh
Smart Analytics
AI Gợi ý Bối cảnh & Tính KPI tự động

Tự đọc cấu trúc cột doanh thu, giá vốn, kênh bán để đề xuất câu hỏi nghiệp vụ; tính ngay ROS, AOV và vẽ biểu đồ Chart.js kèm nhận xét dưới từng biểu đồ.

4. Báo Cáo Chuẩn, Chatbot & Bảo Mật
Executive Output
Sửa trực tiếp + Xuất HTML/PDF + Trợ lý 24/7

Tạo Executive Summary & văn bản báo cáo chuẩn doanh nghiệp; tích hợp Chatbot AI giải đáp, đăng nhập cá nhân hóa avatar và lớp bảo mật chống sập trang.

Mỗi bước vận hành vừa nhanh gọn bằng AI vừa đảm bảo độ tin cậy cho người ra quyết định Slide 5 / 7

🎬 Kịch bản Demo 3 Phút trên lớp
  • Phút 1 — Đăng nhập & Nạp dữ liệu: Giới thiệu giao diện đăng nhập trong suốt, thử chuyển giữa Tải tệp / Google Sheet / Lark Base và bấm ⚡ Nạp Mẫu Hưng Phát (hoặc thử nạp file rỗng).
  • Phút 2 — Làm sạch theo lệnh & Hoàn tác: Mở Làm sạch theo lệnh, nhập câu "Xóa 5 dòng dữ liệu đầu tiên" xem AI cắt dòng ngay, sau đó bấm ↩️ Hoàn tác để khôi phục.
  • Phút 3 — Phân tích BI & Xuất Báo cáo: Bấm ✅ Duyệt dữ liệu xem Dashboard KPI, thử sửa tay vào Báo cáo chiến lược, hỏi Chatbot AI và bấm Xuất HTML.
